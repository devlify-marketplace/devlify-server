# Devlify Server

**Type-Safe API Framework for Bun by [Devlify Marketplace](https://github.com/devlify-marketplace)**

An ergonomic, high-performance web framework built for Bun with end-to-end TypeScript type safety. 18× faster than Express.

## Features

- **End-to-end type safety** — Like tRPC but for HTTP APIs
- **18× faster than Express** (TechEmpower benchmarks)
- Built-in OpenAPI documentation generation
- Frontend RPC connector for seamless client-server typing
- WinterCG compliant

## Quick Start

```bash
bun create elysia app
cd app
bun run dev
```
